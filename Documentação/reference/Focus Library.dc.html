Technical exceptions
Ring at 340px

CircularProgress takes size/thickness but not a two-tone track — add the pale ring as an absolutely positioned second CircularProgress with value={100}.

Sound cards that light up

The tinted card + border that activates with volume is a styled('div') reading level > 0; MUI has no such state.

Rounded fonts

Load @fontsource/quicksand and @fontsource/nunito before ThemeProvider; Quicksand has no italic, so emphasis uses weight only.

Two themes, one tree

buildTheme(mode) in one ThemeProvider with CssBaseline; skip MUI's colorSchemes so both pastel sets stay hand-tuned.
